# Setup Guide

## Local Development

```bash
git clone https://github.com/naveensharmatech/b2b-lead-generator.git
cd b2b-lead-generator
npm install
npx apify-cli run
```

## Apify Deployment

1. Create account at apify.com
2. Connect GitHub repository
3. Configure input schema
4. Deploy via CLI or UI

## API Usage

Use the Apify API to trigger runs programmatically and integrate with your workflows.
